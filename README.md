# SpotPilot AI

داشبورد فارسی برای بررسی بازار رمزارزها با داده‌های عمومی. این برنامه **معامله انجام نمی‌دهد** و سفارش ثبت نمی‌کند.

## قابلیت‌ها

- غربال اولیه ارزها با داده‌های LiveCoinWatch و حداقل حجم ۲۴ ساعته
- مقایسه قیمت عمومی چند صرافی از طریق CCXT و LBank
- تحلیل کندل‌های بسته‌شده LBank در تایم‌فریم‌های ۱۵ دقیقه، ۴ ساعت و روزانه
- نمودار کندل‌استیک تعاملی همراه با SMA 14/50/200، حد متحرک UT و علامت‌های UT
- بررسی دفتر سفارش و معاملات اخیر LBank
- خروجی گزارش PDF از داده‌ها و تحلیل‌های موجود در صفحه

## اجرا روی Streamlit Community Cloud

1. مخزن را به Streamlit Community Cloud متصل کن.
2. فایل اصلی را روی `app.py` قرار بده.
3. در بخش **App settings → Secrets** کلید LiveCoinWatch را به این شکل اضافه کن:

```toml
LIVECOINWATCH_API_KEY = "کلید-واقعی-شما"
```

4. در تنظیمات استقرار، `app.py` را به‌عنوان فایل اصلی انتخاب کن. وابستگی‌ها از `requirements.txt` نصب می‌شوند.
5. پس از هر Commit، منتظر بمان تا Streamlit برنامه را بازسازی کند. در صورت خطا، بخش **Manage app → Logs** را بررسی کن.

**کلید API را در کد، README، Issue یا مخزن عمومی قرار نده.** فقط از بخش Secrets استفاده کن.

## اجرای محلی

به Python 3.10 یا جدیدتر نیاز است. در محیط مجازی:

```bash
pip install -r requirements.txt
streamlit run app.py
```

برای دریافت فهرست ارزها باید `LIVECOINWATCH_API_KEY` در Secrets استریم‌لیت تنظیم شده باشد. سایر داده‌های LBank و قیمت صرافی‌ها از APIهای عمومی دریافت می‌شوند؛ در صورت محدودیت شبکه یا API ممکن است برخی بخش‌ها موقتاً در دسترس نباشند.

## داده‌های CryptoMeter.io برای تحلیل نقدینگی

- برای استفاده از API، یک کلید از [مدیریت API CryptoMeter](https://www.cryptometer.io/api-manage) بگیر و در **Streamlit → App settings → Secrets** به این صورت تنظیم کن:

```toml
CRYPTOMETER_API_KEY = "کلید-واقعی-شما"
```

- APIهای بدون برچسب Paid که در داشبورد استفاده می‌شوند: `trend-indicator-v3` (فشار خرید/فروش تجمیعی بازار)، `merged-orderbook` (دفتر سفارش تجمیعی چند صرافی)، `rapid-movements` (حرکت‌های سریع ۴ ساعت اخیر) و `tickerlist` (تغییر و حجم بازار اسپات Binance).
- در expander مربوط به CryptoMeter می‌توان به‌صورت اختیاری `24h-trade-volume-v2` (خرید/فروش ۲۴ساعته)، `open-interest` و `long-shorts-data` را برای ارز انتخاب‌شده از Binance Futures دریافت کرد. این سه endpoint فقط با فعال‌کردن گزینه داخل پنل فراخوانی می‌شوند تا مصرف سهمیه کنترل شود.
- پاسخ‌های CryptoMeter تا ۱۵ دقیقه cache می‌شوند تا با سهمیه رایگان ۱۰٬۰۰۰ درخواست در ماه سازگارتر باشد. هر endpoint به API key نیاز دارد؛ کلید را در مخزن عمومی قرار نده.
- `volume-flow`، `liquidity-lens` و `xtrades` در مستندات API برچسب **Paid** دارند؛ نسخه فعلی آن‌ها را فراخوانی نمی‌کند. پیش‌نمایش‌های رایگان سایت با دسترسی رایگان API یکسان نیستند.
- داده‌های تجمیعی CryptoMeter مختص LBank نیستند. شاخص فشار خرید/فروش و دفتر سفارش از چند صرافی‌اند؛ داده‌های Open Interest و Long/Short در این پنل از Binance Futures هستند. هیچ‌کدام به‌تنهایی جهت آینده قیمت را تضمین نمی‌کنند.

## معنی شاخص‌ها

- **SMA 14/50/200:** میانگین قیمت بسته‌شدن تعداد مشخصی از کندل‌های اخیر؛ عدد دوره به معنی روز نیست و با تایم‌فریم تغییر می‌کند.
- **ATR:** برآورد دامنه نوسان اخیر؛ پیش‌بینی جهت قیمت نیست.
- **حد متحرک UT / UT Bot:** شاخص دنبال‌کننده روند که ممکن است علامت‌های خرید یا فروش تولید کند؛ به‌تنهایی معیار تصمیم نیست.
- **فاصله خرید و فروش (Spread):** فاصله نسبی بهترین سفارش فروش و خرید قابل‌مشاهده.
- **عدم‌تعادل دفتر سفارش:** تفاوت نسبی ارزش سفارش‌های خرید و فروشِ قابل‌مشاهده؛ سفارش‌ها ممکن است لغو شوند.
- **جریان معاملات اخیر:** جمع ارزش معاملاتی که API توانسته سمت خرید یا فروش آن‌ها را طبقه‌بندی کند؛ لزوماً تمام بازار را پوشش نمی‌دهد.

## محدودیت‌ها

- داده‌ها و نتایج به کیفیت و دسترس‌پذیری APIهای عمومی وابسته‌اند.
- اختلاف قیمت بین صرافی‌ها به‌تنهایی فرصت آربیتراژ نیست؛ کارمزد، نقدشوندگی، تأخیر و امکان اجرای سفارش مهم‌اند.
- سطوح دفتر سفارش و سناریوهای ورود/خروج تخمینی هستند؛ سفارش‌های بزرگ ممکن است لغو شوند.
- BOS/CHoCH در این نسخه تقریبی است و خروجی شاخص‌ها تضمینی برای سود نیست.
- دریافت کندل‌های LBank به‌صورت صفحه‌بندی‌شده انجام می‌شود تا محدودیت تعداد ردیف هر پاسخ، کندل‌های جدید را حذف نکند؛ کندل باز حذف می‌شود و زمان آخرین کندل در گزارش با سن داده نمایش داده می‌شود.
- قیمت‌های بسیار غیرعادی (مثلاً بالاتر از یک میلیون دلار برای هر واحد) به‌جای حذف خودکار با برچسب «بررسی دستی» مشخص می‌شوند؛ این هشدار به‌تنهایی اثبات خطا نیست.
- گزارش PDF برای خوانایی، آخرین ۲۴ کندل هر تایم‌فریم را در جدول فشرده می‌آورد و خلاصه BTC/XAUT، رتبه‌بندی، نقدینگی و داده‌های اختیاری CryptoMeter/لیکوییدیشن را در صورت موجود بودن اضافه می‌کند.
- درصدهای بسیار کوچک، از جمله فاصله خریدوفروش، طوری قالب‌بندی می‌شوند که مقدار غیرصفر به اشتباه ۰٫۰۰۰۰٪ نمایش داده نشود.
- خروجی PDF و نمودارها باید پس از هر تغییر در محیط استقرار بررسی شوند.

این ابزار برای بررسی و آموزش است، نه توصیه مالی. قبل از هر تصمیم، مدیریت ریسک و شرایط واقعی بازار را مستقلاً بررسی کن.

## واچ‌لیست ثابت و نسبت به BTC

- فهرست اصلی همیشه با این ترتیب شروع می‌شود: **BTC/USDT، XAUT/USDT، SOL/USDT، ETH/USDT**؛ این چهار مورد از فیلتر حداقل حجم مستثنا هستند.
- بخش «ارزش نسبت به بیت‌کوین» از جفت‌ارز مستقیم دارایی/BTC در LBank استفاده می‌کند؛ اگر جفت مستقیم وجود نداشته باشد، نسبت از کندل‌های واقعی دارایی/USDT و BTC/USDT محاسبه و به‌عنوان نرخ متقاطع مشخص می‌شود. اگر داده کافی نباشد، مقدار نمایش داده نمی‌شود.

## نقشه لیکوییدیشن رایگان

- برنامه برای نمایش لیکوییدیشن‌های **واقعاً اجراشده** از endpoint عمومی SmartMoneyAPI استفاده می‌کند؛ طبق مستندات ارائه‌دهنده رایگان و بدون کلید است، اما محدودیت درخواست بر اساس IP دارد.
- این داده با نقشه تخمینی سطوح احتمالی لیکوییدیشن تفاوت دارد و مربوط به جریان بازارهای فیوچرز چند صرافی است، نه صرفاً دفتر سفارش اسپات LBank.
- برای نقشه تخمینی و رایگان که با داده عمومی Bybit محاسبه می‌شود، [LiqMap](https://liqmap.smithblock.ai/) را ببین.
- [CoinGlass](https://www.coinglass.com/pro/futures/LiquidationHeatMap) برای مشاهده دستی همچنان قابل باز کردن است، اما API نقشه حرارتی آن در پلن‌های فعلی رایگان نیست.


## تفسیر نقدینگی و تخصیص طلا/رمزارز

- نقشه SmartMoneyAPI در برنامه، **لیکوییدیشن‌های واقعاً ثبت‌شده در گذشته نزدیک** را نشان می‌دهد؛ به‌تنهایی محل نقدینگیِ هنوز فعال یا جهت حرکت بعدی قیمت را پیش‌بینی نمی‌کند.
- دیوارهای دفتر سفارش LBank به‌عنوان سطوح احتمالیِ قابل آزمایش بررسی می‌شوند. این سفارش‌ها ممکن است لغو شوند؛ نزدیک‌تر بودن به معنی قطعیت در جمع‌آوری نقدینگی نیست.
- در برخورد با سطح، برنامه راهنمای تأیید واکنش، شکست/تثبیت، sweep و بازپس‌گیری سطح و تعیین حد ابطال را نشان می‌دهد.
- برای مقایسه بیت‌کوین با طلا، نسبت مصنوعی **BTC/XAUT** از تقسیم کندل‌های واقعی BTC/USDT بر XAUT/USDT ساخته می‌شود. این نرخ متقاطع است و ادعا نمی‌کند جفت مستقیم BTC/XAUT در LBank وجود دارد.
- جمع‌بندی خودکار بین ۱۰۰٪ رمزارز، ۱۰۰٪ XAUT یا ترکیب ۵۰/۵۰ انتخاب می‌کند. فقط وقتی نسبت BTC/XAUT و روندهای ۴ساعته/روزانه هم‌جهت باشند، مدل گزینه ۱۰۰٪ را نشان می‌دهد؛ در حالت مبهم یا داده ناکافی، ترکیب را ترجیح می‌دهد.
- این درصدها سیگنال قاعده‌محور عمومی هستند، نه مشاوره مالی شخصی یا تضمین بازده. XAUT توکن طلای دیجیتال است و ریسک ناشر، نگهداری و صرافی دارد.


## رتبه‌بندی ساده رمزارزها و تفسیر نقدینگی

- بخش «اولویت رمزارزها برای بررسی خرید» از رمزارزهای موجود در فهرست که در LBank جفت USDT دارند، یک فهرست کوتاه می‌سازد و با داده واقعی ۴ساعته/روزانه، عملکرد نسبت به BTC، تغییر ۲۴ساعته و حجم، آن‌ها را رتبه‌بندی می‌کند.
- «اولویت ۱» فقط یعنی ارزش بررسی بیشتر دارد؛ برای ورود، باید نقطه ورود و واکنش قیمت به سطح نیز تأیید شود. اگر امتیاز پایین یا داده ناقص باشد، برنامه خرید فوری را تأیید نمی‌کند.
- «بهترین قیمت خرید» و «بهترین قیمت فروش» فقط دو قیمت برتر دفتر سفارش برای محاسبه اسپرد هستند؛ آن‌ها لزوماً ناحیه‌های انباشت نقدینگی نیستند.
- تحلیل نقدینگی، سفارش‌های دفتر LBank را در بازه‌های قیمتی ۰٫۱۰٪ تجمیع می‌کند و ناحیه‌ها را بر اساس ارزش کل سفارش‌ها رتبه‌بندی می‌کند؛ بنابراین ناحیهٔ قوی‌تر لزوماً نزدیک‌ترین ناحیه نیست. قیمت نمایش‌داده‌شده برای هر ناحیه میانگین وزنی ارزش سفارش‌هاست.
- ناحیه‌های تجمیعی فقط سفارش‌های قابل‌مشاهده همان دفتر سفارش را پوشش می‌دهند؛ سفارش‌ها ممکن است لغو شوند و این داده‌ها ثابت نمی‌کنند قیمت حتماً برای شکار نقدینگی به آن سطح می‌رود.
