# SpotPilot AI — نسخه دارای خروجی PDF

## فایل‌ها
- `app.py`: کد کامل برنامه با دکمه دانلود گزارش PDF چندصفحه‌ای.
- `requirements.txt`: وابستگی‌های لازم برای Streamlit، داده‌های بازار و PDF.

## راه‌اندازی
1. فایل‌های `app.py` و `requirements.txt` را در ریشه مخزن GitHub پروژه جایگزین کنید.
2. تغییرات را Commit کنید تا Streamlit Community Cloud برنامه را بازسازی کند.
3. کلید LiveCoinWatch را فقط در بخش Secrets قرار دهید:

```toml
LIVECOINWATCH_API_KEY = "کلید-شما"
```

کلید را در کد یا مخزن GitHub قرار ندهید.

## خروجی PDF
دکمه «دانلود گزارش کامل PDF» در پنل قرار دارد و گزارش را به شکل چندصفحه‌ای می‌سازد. نمایش درست فارسی به فونت مناسب در محیط اجرا وابسته است؛ اگر فونت فارسی روی محیط میزبانی در دسترس نباشد، ممکن است شکل‌دهی متن نیاز به تنظیم بیشتر داشته باشد.

## وضعیت بررسی
فایل `app.py` از نظر syntax پایتون بررسی شده است. اتصال زنده APIها، استقرار Streamlit Cloud و کیفیت PDF روی محیط نهایی هنوز در این بسته آزمایش نشده‌اند.
